## Start application

To start the game, make sure to have **Gradle** installed on your device. Afterwards you can simply run the following command.

```shell
gradle run
```

This command automatically compiles the programm and starts it.

## Run tests

To run automated tests execute the following command.

```shell
gradle test
```
